# Wiki Tag Taxonomy

## Period Tags

| Tag | Description | Examples |
|-----|-------------|----------|
| `stone-age` | Pre-metal age (c. 300,000 BCE - 3,300 BCE) | Stone tools, choppers, axes |
| `bronze-age` | Bronze metal age (c. 3,300 BCE - 1,200 BCE) | Bronze tools, metallurgy |
| `neolithic` | Agricultural Revolution (c. 12,000 BCE - 3,300 BCE) | Agriculture, domestication |
| `chalcolithic` | Copper age (c. 4,500 BCE - 3,300 BCE) | Copper tools, early metallurgy |
| `upper-stone-age` | Upper Paleolithic (c. 200,000 - 10,000 BCE) | Upper Paleolithic tools |
| `lower-stone-age` | Lower Paleolithic (c. 10,000 - 10,000 BCE) | Upper Paleolithic tools |
| `early-bronze-age` | Early Bronze Age (c. 3,300 - 2,500 BCE) | Early Bronze Age technologies |
| `paleolithic` | Paleolithic period | Paleolithic tools, art |
| `mesolithic` | Mesolithic period | Microliths, fishing |
