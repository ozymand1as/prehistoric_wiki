# Hearth and Floor Analysis

Hearth and floor analysis uses geoarchaeological methods to reconstruct domestic activities, spatial organization, and site formation processes from the microscopic and chemical traces preserved in occupation surfaces.

## Overview

Hearths and floors are the primary loci of domestic activity. Their microscopic residues—ash, charcoal, phytoliths, lipids, blood proteins—encode information about diet, fuel, technology, and spatial organization.

## Hearth Analysis

### Hearth Types
| Type | Period | Construction |
|------|--------|--------------|
| **Simple pit** | Paleolithic+ | Shallow depression |
| **Stone-lined** | Mesolithic+ | Stone ring, clay base |
| **Clay-rimmed** | Neolithic+ | Raised clay collar |
| **Raised hearth** | Bronze Age+ | Platform, often tiled |
| **Oven** | Neolithic+ | Domed, enclosed |

### Hearth Residues
- **Macro**: Charcoal (fuel), bone (cooking), seeds (parching)
- **Micro**: Ash (mineral), phytoliths (plant parts), spherulites (dung)
- **Chemical**: Phosphates (organic), lipids (cooking), isotopes (diet)
- **Magnetic**: Thermoremament magnetism (temperature)

### Activity Inference
- **Primary**: Cooking, heating, lighting
- **Secondary**: Tool heat-treating, hide smoking, ceramic firing
- **Social**: Gathering, storytelling, ritual

## Floor Analysis

### Floor Types
| Type | Composition | Period |
|------|-------------|--------|
| **Earth** | Compacted clay/silt | Paleolithic+ |
| **Plaster** | Lime, clay, gypsum | Neolithic+ |
| **Stone** | Flagstone, pebble | Neolithic+ |
| **Wood** | Plank, split log | Neolithic+ |
| **Turf/sod** | Grass root mat | Mesolithic+ |

### Microstratigraphy
- **Laminations**: Sequential occupation layers
- **Trample zones**: Compaction, micro-artifacts
- **Activity residues**: Drop zones, sweep margins
- **Burn patches**: In situ fires, hot stones

### Phytolith & Micromorphology
- **Phytoliths**: Silica bodies → plant processing
- **Dung spherulites**: Animal presence, stabling
- **Ash pseudomorphs**: Fuel type, temperature
- **Bone fragments**: Butchery, marrow extraction

## Spatial Analysis

### Activity Areas
- **Hearth center**: Cooking, social focus
- **Hearth periphery**: Tool maintenance, eating
- **Wall zones**: Storage, sleeping, specialized
- **Entrance**: Transition, draft control, refuse

### Refuse Patterns
- **Primary**: In situ (ash, large bones)
- **Secondary**: Swept to margins, pits
- **De facto**: Abandoned in place (tools, ornaments)

## Analytical Methods

| Method | Target | Resolution |
|--------|--------|------------|
| **Micromorphology** | Sediment fabric | µm-mm |
| **Phytolith analysis** | Plant silica bodies | 10-100 µm |
| **Lipid biomarkers** | Cooking fats, oils | ng-g |
| **Phosphate mapping** | Organic enrichment | m² |
| **Magnetic susceptibility** | Burning, enhancement | cm³ |
| **FTIR** | Mineral, organic | µm |
| **Stable isotopes** | Diet, fuel | ‰ |
