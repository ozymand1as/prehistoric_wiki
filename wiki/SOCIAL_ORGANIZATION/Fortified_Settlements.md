# Fortified Settlements

Fortified settlements are communities protected by artificial defensive works—walls, ditches, palisades, ramparts, and citadels. They represent the architectural manifestation of intergroup conflict and the increasing importance of territorial defense. [1]

## Overview

Fortification marks the transition from communities that rely on mobility or kinship for defense to those that invest in fixed, labor-intensive defensive infrastructure. It correlates with sedentism, resource concentration, and political centralization.

## Fortification Types

### Neolithic / Chalcolithic
| Type | Example | Features |
|------|---------|----------|
| **Tower** | Jericho (9,500 BCE) | Stone tower, 8.5 m high |
| **Wall** | Jericho, Çatalhöyük (dense housing) | Stone, mudbrick |
| **Ditch** | Çayönü, Abu Hureyra | Perimeter ditch |
| **Palisade** | LBK settlements | Timber, earth |

### Bronze Age
| Type | Example | Features |
|------|---------|----------|
| **Cyclopean walls** | Mycenae, Tiryns, Hattusa | Massive stone, no mortar |
| **Citadel** | Mycenae, Troy, Knossos | Elevated, fortified core |
| **City wall + gates** | Uruk, Ur, Babylon | Mudbrick, baked brick, gatehouses |
| **Causewayed enclosures** | Britain, Europe | Interrupted ditches, Neolithic |

### Regional Variations
| Region | Style |
|--------|-------|
| **Near East** | Mudbrick, baked brick, buttressed |
| **Aegean** | Cyclopean stone, corbelled gates |
| **Europe** | Earthwork, timber palisade, hillfort |
| **China** | Rammed earth (pisé), Hangtu |
| **Mesoamerica** | Stone veneer, earth core |
| **Andes** | Stone, adobe, hilltop |
| **North America** | Palisade, ditch, earthwork (Cahokia) |

## Defensive Features

| Feature | Function |
|---------|----------|
| **Wall** | Physical barrier, psychological |
| **Ditch/Moat** | Impede approach, increase effective height |
| **Glacis** | Sloped approach, prevent scaling |
| **Towers** | Flanking fire, observation |
| **Gatehouse** | Controlled entry, kill zone |
| **Postern** | Secret exit, counterattack |
| **Parapet/Walkway** | Defender platform |
| **Machicolation** | Vertical defense (later) |

## Construction & Labor

### Materials
| Material | Technique |
|----------|-----------|
| **Mudbrick** | Sun-dried, laid in courses |
| **Rammed earth** | Layered compaction (pisé) |
| **Stone** | Dry-stone, cyclopean, ashlar |
| **Timber** | Palisade, laced earth |
| **Earth** | Ditch spoil → rampart |

### Labor Estimates
- **Jericho tower**: ~11,000 person-days
- **Mycenae walls**: ~150,000 person-days
- **Great Wall (Ming)**: Millions of person-years

## Settlement Layout

### Hillforts (Europe)
- **Location**: Hilltop, promontory
- **Ramps**: Multiple ramparts
- **Entrances**: Complex, guarded
- **Interior**: Roundhouses, granaries, reservoirs

### Tell Sites (Near East)
- **Mound**: Accumulated occupation
- **Perimeter wall**: On tell edge
- **Gate**: Controlled access

### Walled Cities
- **Grid plan**: Gates at cardinal points
- **Citadel**: Elite/defense core
- **Suburbs**: Outside walls (later)
